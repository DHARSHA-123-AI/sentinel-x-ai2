
# 🛡️ SENTINEL-X AI PRO

### Intelligent Cybersecurity Threat Analysis Platform

SENTINEL-X AI PRO is a web-based cybersecurity demonstration platform designed to identify suspicious patterns in URLs and email messages. It provides a simple interface to understand potential online threats through risk scoring and security analysis.

## 🚀 Key Features

- 🔐 Login and Sign Up interface
- 📊 Advanced Cybersecurity Dashboard
- 🔍 URL Threat Analysis
- 📧 Email Phishing Pattern Analysis
- 📈 Risk Score Visualization
- 📋 Scan History and Reports
- 🌙 Professional Dark Theme
- 📱 Mobile Responsive Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🎯 Project Objective

The main objective of SENTINEL-X AI PRO is to improve cybersecurity awareness by demonstrating basic suspicious-pattern analysis and helping users understand common online threats.

## ⚙️ How It Works

1. Open the SENTINEL-X AI PRO website.
2. Access the dashboard.
3. Enter a URL or email sample.
4. Run the analysis.
5. View the demo risk score and detected warning patterns.
6. Review previous scans in the history section.

## ⚠️ Disclaimer

This project is an educational prototype. It uses basic pattern-based checks and does not connect to live threat intelligence databases or provide verified AI-based threat detection. Results should not be treated as a guarantee of safety.
